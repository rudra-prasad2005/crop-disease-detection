How to Train / Retrain the Model

1 Local Training (CLI)

Run from the project root. It will extract archive.zip, create 80/20 stratified splits, and run Phase 1 (frozen base) + Phase 2 (fine-tuning top 50 layers): 

python main.py train

2 Google Colab GPU (Fastest)

Open colab_train.ipynb in Google Colab with a free T4 GPU. In 15–30 minutes, it trains the model and outputs best_model.h5. 

# Open colab_train.ipynb on Colab
Fullstack UI is Active! When you run python app.py, this web application connects directly to the backend REST endpoints.
